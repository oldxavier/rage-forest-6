# Rage Forest 6 Stats

Standings, records and oddities from every game of [Rage Forest 6](https://liquipedia.net/ageofempires/Rage_Forest/6), a 4v4 Age of
Empires II tournament for the [Rage Forest community](https://discord.gg/PkvTNwy4vx).

**Site:** https://oldxavier.github.io/rage-forest-6/

Each game's recording is replayed in CaptureAge and logged unit by unit. `site/data/stats.json`
holds everything the page shows and is regenerated as new games are played; the page itself is plain
HTML, CSS and JavaScript in `site/`, built by [castats](https://github.com/oldxavier/castats).

A sibling of [Rage Forest Ratings](https://oldxavier.github.io/rageforest-ratings/).
